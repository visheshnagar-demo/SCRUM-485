# Project Features

## SCRUM-485 - Define and Manage Product Pricing Currencies in Product Catalog

### Feature Summary
Allows catalog managers to manage international currencies, set multi-currency pricing per product, and provide localized store price displays with exchange rate conversion fallback.

### Key Features
- Currency Definition and ISO 4217 Validation
- Product Price Configuration Per Currency
- Base Currency and Exchange Rate Conversion Fallback
- Catalog Frontend Currency Selection and Localized Price Display
- RESTful API Endpoint Integration & Data Integrity
